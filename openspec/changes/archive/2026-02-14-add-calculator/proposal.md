## Why

숫자에 아직 익숙하지 않은 아이들이 자유롭게 숫자와 연산자를 눌러보며 계산 방식을 익힐 수 있는 도구가 필요하다. 기존 퀴즈 모드는 정해진 문제를 풀어야 하지만, 계산기 모드에서는 아이가 스스로 궁금한 숫자 조합을 입력하고 결과를 확인할 수 있다.

## What Changes

- 메인 화면(홈)에 "계산기" 버튼 추가 (기존 연산 선택 버튼 아래)
- 새로운 계산기 화면(screen-calculator) 추가
  - 0~9 숫자 버튼, 사칙연산 버튼(+, −, ×, ÷), = 버튼, C(초기화) 버튼
  - 디스플레이 영역에 입력 중인 식과 결과 표시
  - 정수만 지원 (소수점, 실수, 큰 숫자 제외)
  - 입력 가능한 숫자 범위 제한 (예: 0~999)
  - 나눗셈 결과가 정수가 아닌 경우 나머지 표시 또는 안내
  - 0으로 나누기 시도 시 친절한 안내 메시지
- 기존 사운드 시스템 연동 (버튼 클릭음, = 누를 때 결과음)
- 기존 반응형 레이아웃 스타일 유지 (Jua 폰트, 모바일 대응)

## Capabilities

### New Capabilities
- `calculator`: 아이가 숫자와 연산자를 자유롭게 입력하여 계산 결과를 확인할 수 있는 간단한 계산기 화면

### Modified Capabilities
- `operation-select`: 홈 화면에 "계산기" 버튼 추가

## Impact

- `index.html`: 계산기 화면 HTML 구조 추가, 홈 화면에 버튼 추가
- `js/app.js`: 계산기 화면 전환 로직 및 계산기 동작 로직 추가
- `css/style.css`: 계산기 화면 스타일 추가
- 외부 의존성 변경 없음
