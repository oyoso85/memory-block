## Context

Number Block은 아이들을 위한 수학 퀴즈 앱으로, 바닐라 JS/HTML/CSS로 구성되어 있다. 현재 홈 화면에서 사칙연산을 선택하고 난이도별 문제를 푸는 퀴즈 모드만 존재한다. 아이들이 자유롭게 계산을 탐색할 수 있는 도구가 없다.

## Goals / Non-Goals

**Goals:**
- 홈 화면에서 접근 가능한 간단한 계산기 화면 제공
- 0~999 범위의 정수 사칙연산 지원
- 아이가 숫자 버튼과 연산자 버튼을 눌러 식을 만들고 결과 확인
- 기존 앱의 디자인 패턴(showScreen, Sound 시스템) 재활용

**Non-Goals:**
- 소수점, 실수, 음수 지원 안함
- 괄호, 제곱, 루트 등 고급 연산 안함
- 계산 이력 저장 안함
- 연속 계산(결과를 다음 피연산자로 자동 사용) 안함

## Decisions

### 1. 계산기 로직을 app.js에 추가

별도 JS 파일 대신 기존 app.js의 IIFE 내부에 계산기 로직을 추가한다. 계산기 상태(displayValue, firstOperand, operator, waitingForSecond)를 관리하는 간단한 상태 머신으로 구현한다.

**근거:** 기존 코드가 모두 app.js에서 화면별 로직을 관리하는 패턴이므로 일관성을 유지한다. 계산기 로직이 크지 않아 별도 파일로 분리할 필요가 없다.

### 2. 입력 범위 제한 (0~999)

디스플레이에 표시 가능한 숫자를 최대 3자리(0~999)로 제한한다. 결과도 999를 초과하면 "너무 커요!" 안내를 표시한다.

**근거:** 대상 사용자가 어린이이므로 큰 숫자는 학습 목적에 부합하지 않는다.

### 3. 나눗셈 처리

- 0으로 나누기: "0으로 나눌 수 없어요" 메시지 표시
- 나머지가 있는 나눗셈: 몫만 표시하고 "나머지 N" 을 별도 표시

**근거:** 아이들에게 나눗셈 개념을 정확히 전달하면서도 혼란을 최소화한다.

### 4. 버튼 레이아웃

4×4 그리드 레이아웃:
```
[ 7 ] [ 8 ] [ 9 ] [ ÷ ]
[ 4 ] [ 5 ] [ 6 ] [ × ]
[ 1 ] [ 2 ] [ 3 ] [ − ]
[ C ] [ 0 ] [ = ] [ + ]
```

**근거:** 일반적인 계산기 배치를 따르되, 아이에게 익숙한 형태로 구성한다.

### 5. 화면 전환

홈 화면의 "점수 이력" 버튼 아래에 "계산기" 버튼을 추가하고, 클릭 시 `showScreen('screen-calculator')`로 전환한다.

## Risks / Trade-offs

- **[연속 계산 미지원]** → 1.0에서는 단일 이항 연산만 지원. 추후 요청 시 확장 가능.
- **[큰 결과값]** → 곱하기 결과가 999를 초과할 수 있음 → "너무 커요!" 메시지로 대응.
