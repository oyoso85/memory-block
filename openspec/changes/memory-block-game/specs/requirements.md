# 요구사항

## 블록 개수 선택 화면

- REQ-01: 게임 시작 전 블록 개수 선택 화면을 표시한다
- REQ-02: 2~6개 중 선택할 수 있으며, 각 숫자 버튼으로 제공한다
- REQ-03: 선택 후 해당 개수만큼 블록을 동적으로 생성한다

## 게임 화면 구성

- REQ-04: 블록 색상은 빨강, 파랑, 초록, 노랑, 보라, 주황 (최대 6색)이다
- REQ-05: 블록 배치: 2~4개는 2열, 5~6개는 3열 그리드이다
- REQ-06: 현재 레벨과 최고 기록을 상단에 표시한다
- REQ-07: 게임 상태 메시지를 표시한다 (시작 안내, 순서 기억, 클릭 안내, 게임 오버)
- REQ-08: 게임 시작/재시작 버튼을 제공한다

## 게임 플레이

- REQ-06: 게임 시작 시 랜덤 블록 1개를 시퀀스에 추가한다
- REQ-07: 시퀀스의 블록을 순서대로 반짝이며 보여준다
- REQ-08: 반짝임 지속 시간은 400ms, 블록 간 간격은 200ms이다
- REQ-09: 시퀀스 재생 중에는 플레이어 클릭을 비활성화한다
- REQ-10: 플레이어가 올바른 순서로 모든 블록을 클릭하면 레벨 업한다
- REQ-11: 레벨 업 시 시퀀스에 랜덤 블록 1개를 추가하고 다시 보여준다
- REQ-12: 잘못된 블록을 클릭하면 즉시 게임 오버한다

## 사운드

- REQ-13: 블록이 반짝일 때 해당 블록의 고유 음을 재생한다
- REQ-14: 음악 파일 없이 Web Audio API로 소리를 생성한다
- REQ-15: 각 블록의 주파수: 빨강(262Hz 도), 파랑(294Hz 레), 초록(330Hz 미), 노랑(349Hz 파), 보라(392Hz 솔), 주황(440Hz 라)
- REQ-16: 소리 지속 시간은 300ms이며 자연스럽게 페이드아웃한다

## 기록

- REQ-17: 최고 기록을 블록 개수별로 분리하여 localStorage에 저장한다
- REQ-18: 기존 최고 기록을 넘으면 "새로운 최고 기록" 메시지를 표시한다

## 시나리오

### 정상 플레이 시나리오
1. 플레이어가 블록 개수(2~6) 선택
2. 게임 화면으로 전환, 선택한 개수만큼 블록 표시
3. 플레이어가 "게임 시작" 클릭
2. 블록 1개 반짝임 + 소리
3. 플레이어가 같은 블록 클릭 → 성공
4. 블록 2개 순서대로 반짝임 + 소리
5. 플레이어가 같은 순서로 2개 클릭 → 성공
6. 반복...

### 게임 오버 시나리오
1. 시퀀스 재생 후 플레이어가 잘못된 블록 클릭
2. "게임 오버! 레벨 N까지 도달했습니다" 메시지 표시
3. 최고 기록 갱신 시 별도 메시지 표시
4. "다시 시작" 버튼 활성화
