# Memory Block Game

## 목표

웹 브라우저에서 플레이할 수 있는 기억력 테스트 게임을 만든다.
"사이먼 세이즈(Simon Says)" 스타일의 순서 기억 게임으로,
플레이어의 단기 기억력을 테스트한다.

## 게임 규칙

1. 화면에 4개의 색상 블록이 2x2 그리드로 배치된다
2. 게임이 블록을 하나씩 순서대로 반짝이며 보여준다
3. 플레이어는 같은 순서로 블록을 클릭해야 한다
4. 성공하면 시퀀스에 블록 1개가 추가된다 (레벨 업)
5. 실패하면 게임 오버

## 변경 범위

- 신규 웹 프로젝트 생성 (Vite + 바닐라 JS)
- 게임 UI 구현 (HTML/CSS)
- 게임 로직 구현 (JavaScript)
- 사운드 효과 (Web Audio API)
